# CPP-Mastery

A structured, from-scratch C++ learning repository — built to demonstrate real understanding of C++ fundamentals, data structures, algorithms, and clean coding practice, not just solved problems.

## About

This repo is where I'm rebuilding my C++ foundations properly: implementing core data structures from scratch before relying on the STL, writing my own notes instead of copying documentation, and solving problems with an emphasis on readable, interview-ready code over quick hacks.

It's part of a broader portfolio — see also my [full-stack projects](https://github.com/Prakhar1Ojha) for applied engineering work.
