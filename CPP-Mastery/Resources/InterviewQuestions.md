# Common Interview Questions (C++ specific)

## Language Fundamentals
- Difference between `struct` and `class` in C++
- Stack vs heap memory allocation
- What happens if you don't define a destructor for a class with a raw pointer member?
- `new`/`delete` vs `malloc`/`free`
- Difference between `const char*`, `char* const`, and `const char* const`

## OOP
- Virtual functions and vtable — how does dynamic dispatch work?
- Diamond problem in multiple inheritance and how `virtual` inheritance solves it
- Difference between overloading and overriding
- Pure virtual functions and abstract classes

## Memory
- Smart pointers: `unique_ptr` vs `shared_ptr` vs `weak_ptr`
- What causes a memory leak, and how do you detect one?
- Shallow copy vs deep copy — when do you need a custom copy constructor?

## STL
- How is `std::map` implemented internally? (Red-Black Tree)
- `vector` vs `list` vs `deque` — when to use each
- Time complexity of common STL operations
