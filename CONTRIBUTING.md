# Contributing

This is primarily a personal learning repository, but suggestions and corrections are welcome.

## Guidelines

- Keep the existing file header format for any `.cpp` file (topic, difficulty, complexity, author).
- Notes should be written in your own words — no copy-pasted documentation.
- One concept per file where possible; keep files focused and readable.
- Use meaningful commit messages, e.g. `Implement merge sort`, `Add STL vector notes`.
- No compiled binaries or IDE-specific files — check `.gitignore` before committing.

## Commit Style

```
<Verb> <what changed>

Examples:
Implement binary search tree insertion
Add notes on STL priority_queue
Fix edge case in merge sort
```
